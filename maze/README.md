# Maze data

`the_spiral/matrix/` is the tile map the simulation server loads (`MAZE_DIR=./maze`, `maze_name` in `simulation/base_cafe_spiral/reverie/meta.json`). It is the `matrix` folder of `frontend_server/static_dirs/assets/the_spiral` in [fvdveen/generative_agents](https://github.com/fvdveen/generative_agents).

Only `matrix/` is needed: the server never reads the map graphics (`visuals/`), so they are not included here.

Do not edit these files for the exercises.
